又是CUDA Out of Memory的一天

用cf-billing-guard避免Cloudflare Worker账单爆炸

  • 2026-10-12
  • 作者 Rimuru
  • ~2.03K 字
  • 0 条评论

介绍

Cloudflare Worker 虽然提供了大量的免费调用额度还还配套了非常多的持久化数据库服务，的这些服务在免费额度用完之后就会产生费用。最重要的是如果服务代码中出现无限循环，那么可能会导致账单迅速飙升，产生高额费用。已经有了非常多的先例：
Cloudflare Worker 无限循环导致高额账单的案例
收到 Cloudflare Durable Object 的天价账单，如何应对
I accidentally generated 16 billion Durable Object writes in one month and got slapped with a $36k bill . Here’s exactly how.
Durable Object alarm loop: $34k in 8 days, zero users, no platform warning
相关案例在国内比比皆是，为此本站推出了 cf-billing-guard 工具，用于防止 Cloudflare Worker 账单爆炸。cf-billing-guard 会覆盖项目的 Worker 入口文件，对所有的调用请求进行计数和限流，对单次请求的数据库等服务调用设置上限，从而有效防止账单异常增长。项目采用 Trusted Publisher 方式发布，确保npmjs包的安全性，有效保护用户的数据安全。
